iq-genius_app
A modern IQ Testing application built with Flutter, migrated from a React + TypeScript project. Features spatial, logic, numerical, and verbal reasoning tests with real-time scoring and performance analytics.

🌟 Features
Diverse Reasoning Tests: Comprehensive assessments covering spatial, logic, numerical, and verbal reasoning.

Real-time Scoring: Instant calculation and feedback as users complete tests.

Performance Analytics: Detailed insights and metrics to track user progress over time.

🚀 Getting Started / Cara Instalasi
Ikuti langkah-langkah di bawah ini untuk menyiapkan dan menjalankan proyek iq-genius_app di komputer lokal Anda:

Prasyarat
Pastikan Anda telah menginstal software berikut di komputer Anda:

Git

Flutter SDK (versi stabil terbaru)

Editor kode seperti VS Code atau Android Studio

Langkah-langkah Instalasi
Clone Repository
Buka terminal atau command prompt, lalu clone repository ini ke perangkat lokal Anda:

Bash
git clone https://github.com/gianalfa-bit/iq-genius_app.git
Masuk ke Direktori Proyek

Bash
cd iq-genius_app
Install Dependencies
Jalankan perintah berikut untuk mengunduh semua paket dan dependencies Flutter yang dibutuhkan:

Bash
flutter pub get
Jalankan Aplikasi
Hubungkan perangkat fisik (Android/iOS) atau nyalakan emulator/simulator Anda, lalu jalankan aplikasi dengan perintah:

Bash
flutter run
